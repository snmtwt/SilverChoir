# 单位实体配置与展示台

展示台在 BeginPlay 自动注册至玩家单位子系统，在 EndPlay 自动注销。蓝图使用“获取单位展示台”节点取得引用，再调用“根据单位ID展示单位”。展示台尚未开始运行或地图已卸载时返回空，请先判断有效性。子系统仅持有弱引用；若误放置多个展示台，保留第一个并输出警告。

- `FUnitTemplate.EntityData` 和 `FUnitData.EntityData` 使用 `FUnitEntityData`。
- 在模板表的“单位实体配置 → 单位实体类”选择 `AUnitPawnBase` 子类（例如 BP_UnitPawn）。默认留空，旧存档/已加载数据不会自动回填；请重新从模板创建单位或通过共享数据的 Modify 更新配置。
- 从模板创建数据、复制数据和管理类加载数据都会保留 EntityData。
- 后续实体相关参数添加到 FUnitEntityData，避免在模板和实例中分别定义。

创建 `UnitDisplayStand` 的蓝图子类并放入地图。DisplayAnchor 是地台底面的中心，放在地面即可。原生 PlatformMesh 使用 `/Game/System/Object/Unit/Display/SM_UnitDisplayPlatform`：直径约 140 cm、高 12 cm，带倒角、哑光顶面和青色细灯带。可在蓝图组件详情中替换模型、材质和调整变换。生成后根据实际地台顶面与人物胶囊半高自动抬升人物；`DisplayHeightOffset` 用于脚底微调。旧蓝图若手动为 DisplayAnchor 加过 92 cm 胶囊高度，需要去掉这段补偿（L_BaseTemplate 中当前展示台没有该补偿）。

调用“根据单位ID展示单位”，传入玩家单位子系统中已经加载的 FGuid。返回生成的单位 Pawn；其 BindUnitData 绑定权威共享数据，并沿用单位数据修改通知。数据查询失败、类为空或生成失败时返回空并保留原展示。

每个展示台仅保留一个展示实体，成功替换时销毁旧实体。提供“获取当前展示单位”和“清空展示单位”。展示台结束运行时自动销毁展示实体，实体自行解绑数据事件。

生成并绑定单位数据后，展示台调用 SIS 函数库的 `LoadItemDatasToInventoryComponent`（当前插件的 Load Item Data 节点），将 `FUnitData.InventoryItems` 加载到实体的 `UnitInventoryComponent`，不重新生成物品 ID。展示实例关闭 `bInitializeFromPreset`，避免预设装备先行初始化。装备槽位和装备生成事件沿用 SIS 配置；此步骤为展示时单向加载，不会把展示库存修改自动写回单位数据。

展示实体关闭自动控制、复制、碰撞及 Mover 模拟后端，保留网格动画。这是专用预览实例，不应直接改作战斗实体。实体蓝图的 Construction/BeginPlay 仍会执行，展示蓝图请避免自行生成控制器或触发战斗逻辑。展示台不自动创建相机或绑定 UI，由界面选人事件调用展示函数。

展示动画通过 HMSAnimationData 固定为 OnGround、零移动输入，不再自动跟随已停用 Mover 的初始 Falling 状态。小队生成器仍使用正常运动模拟。

鼠标旋转由业务蓝图决定何时开启：鼠标按下/拖动开始时，调用“开始鼠标旋转展示单位”，传入本地玩家控制器；鼠标抬起、取消拖动或离开页面时，调用“结束鼠标旋转展示单位”。开始节点返回是否成功。“正在鼠标旋转展示单位”可查询状态。开启后展示台每帧读取水平鼠标位移，只旋转人物，不旋转地台、不改变输入映射或鼠标捕获。`MouseRotationSensitivity` 默认 0.35 度/位移单位，负值可反向。结束后关闭 Tick；替换、清空展示或销毁展示台也会结束旋转。

“开始鼠标旋转展示单位”的“反转鼠标横向旋转”布尔输入默认为 false，勾选后将本次鼠标拖动方向反转；已经开始旋转时再次调用也可以更新该设置。结束旋转后重置，不影响下一次默认调用。建议灵敏度保持正数，用此输入切换方向（负灵敏度叠加反转会再次翻转）。

如果 UMG 自己处理拖动，也可直接调用“旋转展示单位”并传入 MouseDeltaX；这种接法不要同时开启自动鼠标旋转，以免重复处理位移。开始节点的反转输入仅作用于自动读取的鼠标位移，手动传入的 MouseDeltaX 保持原含义。
