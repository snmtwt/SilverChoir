# 单位与小队生成

`AUnitSpawner` 是统一实体生成入口，位于玩家单位子系统目录。C++ 调用 `SpawnUnitShared(TSharedPtr<FUnitData>, OutError)`，直接使用管理器持有的同一份数据，不复制单位记录。实体类读取 `FUnitData.EntityData.UnitPawnClass`。

蓝图可以放置或 Spawn Actor 创建 **单位生成器**，然后调用 **根据单位ID生成单位** 或 **根据单位数据引用生成单位**。后者接 `UUnitDataReference`。单位生成器负责创建实体、绑定数据、恢复库存以及清理旧实体。新实体成功后才替换旧实体；无效数据会返回错误并保留旧实体。

生成位置使用 `SpawnAnchor` 的世界变换，指向 Pawn 胶囊中心。实体在构造和 BeginPlay 前已持有共享数据；初始数据/选中通知等到组件初始化完成后派发。蓝图可在 **单位生成完成** 中连接后续业务。

`AUnitDisplayStand` 继承 `AUnitSpawner`，保留原来的 `DisplayAnchor`、**根据单位ID展示单位**、**清空展示单位**、**获取当前展示单位** 以及展示台注册逻辑。它只负责预览差异：禁用移动、碰撞、网络复制和框选，并附着到展示锚点。原先的展示台蓝图继续使用，无需重新创建。

## 小队生成

创建 **小队生成器** `AUnitSquadSpawner` 后，调用 **根据小队ID生成小队**。它读取玩家小队的成员 ID，依次取得权威单位数据，在自身周围生成多个 `AUnitSpawner`，再由每个生成器创建一名单位。

可配置：

- **单位生成器类**：默认 `AUnitSpawner`，可替换为自己的子蓝图。
- **每行人数**：默认 3。
- **单位间距**：默认前后排距和左右间距均为 160 cm。
- **生成位置偏移**：默认 Z=92 cm，用于把默认胶囊中心抬离地面。

队形居中排列，位置随小队生成器平移、旋转，不随其缩放改变间距。各单位生成器和 Pawn 归属同一个关卡，因此动态子地图卸载时会一起清理；地图加载位置偏移已包含在世界变换内，不需要再次叠加。

**计算小队生成位置** 可查询布局；**获取小队单位生成器** 和 **获取生成小队单位** 可取得结果。重复生成成功后替换原队；成员配置不完整或生成失败时清理本次新建对象并保留旧队。**清空生成小队** 以及销毁小队生成器都会清理它所拥有的生成器和单位。

初版按明确的世界位置生成，不自动投射地面或寻找导航点。生成器应放在已知可站立的位置，并根据实际胶囊高度设置 Z 偏移。单位装备后的属性、阵营、AI 命令等后续业务可接 **小队生成完成** 蓝图事件。

蓝图接入顺序：`Spawn Actor from Class（小队生成器或其子蓝图）` → 设置每行人数、间距、偏移 → **根据小队ID生成小队**。检查返回的成功标记和错误文本；保存生成器引用，后续用它查询成员或清空小队。如果需要让小队随子地图卸载，优先把生成器放在对应子地图内；动态创建时要让生成器本身属于该子地图关卡。

“生成完成”事件发生在新对象提交后，允许业务在事件中继续修改对象。全队回滚保障覆盖创建、初始化阶段，不撤销完成事件中主动执行的业务操作。
