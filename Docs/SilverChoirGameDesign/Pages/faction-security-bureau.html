阵营与角色

安图恩城市警卫总署

每个城市都有的警察部队。玩家在街上亮出带有威胁性的武器会触发攻击；当民众支持度提高，局长会主动谈判并可能加入玩家阵营。

阵营定位

正式名称安图恩城市警卫总署
英文名称Anthuen Civic Guard
常用称呼城盾局、城盾
关键词城市治安、持械反应、局长谈判、防弹护甲、秩序合法性。
玩家关系早期是城市规则压力，中后期可被民意推动成为同盟。
核心矛盾他们维护秩序，但秩序本身可能被腐败、政府军或地方势力利用。
可交易筹码城市通行便利、防弹衣单位、执法情报、区域封锁解除。

主营业务与资源来源

本区域用于说明该势力如何获得资源、向外输出什么，以及它在安图恩产业链中的位置。“业务”同时包含商业经营、公共职能、军事活动和非法收入。
核心业务城市治安、巡逻执法、案件调查、通行管理、区域封锁与公共秩序维护。
主要收入或资源来源政府预算、城市财政、罚没收入、行政费用和地方公共安全合同。
上游依赖财政拨款、警用装备、人员编制、居民报案、监控数据和政治授权。
下游输出城市通行、执法情报、证据、区域封锁、治安单位和没收物资。
产业交叉与合作待补充与政府军、地方政府、商业势力、黑帮和民间组织的合作或渗透关系。
违法或争议环节受贿、保护费、证据买卖、罚没物资侵吞和被政府军或黑帮利用。

玩法功能

持械威胁反应

在城市公共区域公开威胁性武器会触发城市警卫总署攻击或警戒。

民意谈判

民众支持度达到阈值后，局长主动接触玩家，开启同盟路线。

高护甲单位

加入后提供穿戴防弹衣的单位，适合城市推进和火线控制。

角色功能人物钩子
警卫总署署长谈判对象现实主义者，不完全正直，但会被民意和城市安危逼向玩家。
巡逻队长城市规则教学第一次因玩家亮武器而阻拦玩家，建立城市行为边界。
腐败内鬼支线反派把警卫总署资源卖给黑帮或政府军，引发玩家清洗选择。

任务与选择

  • 街区禁枪：玩家学习隐藏武器、绕路或谈判机制。
  • 署长会谈：用民众支持、证据或威胁争取城市警卫总署中立。
  • 清理内鬼：帮助城市警卫总署恢复秩序，或利用内鬼扩大自己的黑色收益。
