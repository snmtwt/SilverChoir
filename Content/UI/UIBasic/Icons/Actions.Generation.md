# Tactical action icons

Production source: editable white SVG geometry and 512 x 512 transparent PNGs in this directory. Texture assets use the same names under `/Game/System/UIBasic/Textures`.

The built-in image_gen tool produced five silhouette studies. Their automatic transparent edges included unwanted speckles. The final icon silhouettes were rebuilt as clean vector artwork to match the existing arrow assets and remain crisp at compact UI sizes. No fallback image API was used.

The five meanings are backpack, pickup/interact hand, observe eye, muted-speaker stealth, and aiming reticle. White RGB enables widget-controlled coloring; no button backgrounds are baked in.

## Generation prompts (concept studies)

### T_ActionBackpack

Use case: logo-brand. Asset type: reusable compact modern tactical game UI icon, part of a cohesive five-icon family. Generate exactly ONE isolated symbol on a truly transparent square 1024x1024 PNG canvas. Style: bold minimalist flat 2D SOLID PURE WHITE #FFFFFF silhouette with a few deliberate transparent cutouts. Clean geometric edges with subtly rounded external corners, no outline shadow. All visible RGB pure white, coverage anti-aliasing in alpha only. Matching line/stroke visual weight around 8 percent of overall icon width where lines occur. Centered, symbol bounding box roughly 68 percent canvas width/height, balanced transparent safe margins. Must remain highly legible in a 20–28 pixel tactical HUD button. No blue, cyan, gray, black, gradients, shading, lighting, texture, tiny intricate details, distressed edges, specks, background, button body, framing, decoration, text, labels or watermark. A modern tactical backpack, straight FRONT VIEW, one strong outer backpack silhouette with a small top carry handle, two compact side pockets, a large front pouch separated by one clear negative-space seam. Restrained symmetric utilitarian shape, no tiny straps or zips. Immediately recognizable as a BACKPACK at 24px.

## 2026-10-05 user revision

T_ActionInteract now uses a rounded, clearly separated five-finger hand silhouette. T_ActionStealth adds two visible sound-wave arcs beside the speaker while retaining the diagonal mute slash. Both keep the same asset identifiers and configurable white tint-mask behavior.

The earlier StanceStanding, StanceCrouching and StanceProne assets were also reimported as pure-white RGB with their original dimensions and alpha bytes unchanged. UE source exports verified all eight icons have white visible pixels and the three stance masks retained exact alpha.
