GSM Grid Strategy Map System

面向 UE 5.8 的网格策略地图运行时与编辑器工具。运行时地图、瓦片和棋子数据独立于 2D/3D 展示对象，支持多地图、数据层寻路、棋子同步和读档前深度清理。

从这里开始

数据模型

地图 GUID、瓦片 ID、棋子 GUID、配置资产与数据对象的职责。

蓝图 API

创建地图、查询、棋子操作、导航和清理节点。

2D 与 3D 展示

地图/瓦片/棋子绑定、事件、缩放、拖拽和路径箭头。

读档与生命周期

深度清理语义、旧引用有效性检查和推荐读档顺序。

最短接入路径

  1. 创建 UGSMMapDataAsset，配置瓦片条目及默认数据/展示类。
  2. 在游戏入口调用 CreateMapData，保存返回的 MapGuid。
  3. 让 AGSMMap3D 以默认地图或指定 GUID 注册并加载 3D 瓦片。
  4. 通过 UGSMMapData 或子系统操作瓦片、棋子与寻路；不要直接把 Actor 当作玩法数据。
  5. 读档前调用 ClearAllMapData，再创建并恢复新地图数据。
