数据模型与配置

数据对象是游戏状态的唯一来源。展示对象可以随场景创建或销毁，不影响地图、瓦片、棋子和寻路数据。

所有权

对象拥有者责任
UGSMMapSubsystemGameInstance默认地图快速访问、非默认地图 GUID Map、3D 地图注册和全局清理。
UGSMMapData子系统一张地图的瓦片、棋子、数据层寻路和地图级事件。
UGSMTileData地图数据一个瓦片的配置副本、玩法扩展字段和所属棋子。
UGSMPieceData地图数据棋子 GUID、所属地图/瓦片、放置参数和可选 3D 类型。
AGSMMap3D 等World可重建的视觉与输入表现，不承担存档权威性。

标识规则

  • 地图：FGuid MapGuid。默认地图走直接变量；其余地图走 GUID Map。
  • 瓦片：FName TileId。未填写时按坐标生成 Tile_X_Y，必须在地图内唯一。
  • 棋子：FGuid PieceGuid。调用方可传入稳定 GUID；传入无效 GUID 时插件自动生成。
存档键推荐使用 MapGuid + TileId + PieceGuid。MapId 是场景展示与兼容入口，不是新玩法数据的主键。

UGSMMapDataAsset

数据资产定义结构和默认类，不保存运行时状态。创建地图数据时，插件会为每个 TileEntries 条目实例化一个瓦片数据对象。

配置项用途
MapDataClass地图数据蓝图/C++ 子类；用于地图级玩法状态。
DefaultTileDataClass瓦片数据默认子类；适合所有权、建筑、单位列表、地形阶段等字段。
DefaultPieceDataClass棋子数据默认子类。
DefaultTileActorClass瓦片 3D 默认展示类；可由单个瓦片条目覆盖。
DefaultPiece3DClass添加棋子时未传 3D 类所使用的默认展示类。
TileEntries瓦片坐标、ID、展示类、数据类、点击权限与导航配置。

扩展位置

需要持久化的玩法状态，请继承 UGSMMapData、UGSMTileData 或 UGSMPieceData。需要网格、动画、材质或交互表现时，再继承相应的 3D Actor。不要把持久游戏状态只写进 AGSMTile3D 或 AGSMPiece3D。
