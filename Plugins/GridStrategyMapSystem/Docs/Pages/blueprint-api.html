蓝图 API

UGSMBlueprintLibrary 提供从任意 World Context 获取子系统、创建/查询地图和读档清理的入口。地图与棋子的细粒度操作位于 UGSMMapData。

地图创建与查询

节点返回/输出说明
CreateMapDataMapGuid、OutMapData按配置资产创建数据地图。默认槽为空时，非默认创建也会成为默认地图。
GetDefaultMapDataUGSMMapData获取默认地图，高频访问优先使用它。
GetMapDataByGuidUGSMMapData获取非默认或指定 GUID 地图。
GetTileDataUGSMTileData按 MapGuid + TileId 查询瓦片数据。
GetGSMMapSubsystemUGSMMapSubsystem需要子系统完整 API 时使用。

3D 地图拖拽与缩放

每项操作分为“默认地图”和“按 GUID 地图”两个节点。默认地图节点没有 GUID 引脚；按 GUID 节点只查询指定地图。地图数据或 3D 地图无效时节点返回 false，输出值会被重置，不需要在蓝图中重复进行空值检查。

默认地图节点按 GUID 节点用途
AddDefaultMap3DZoomAtWorldLocationAddMap3DZoomAtWorldLocationByGuid围绕世界位置进行增量缩放，并输出实际缩放值。
SetDefaultMap3DScaleAtWorldLocationSetMap3DScaleAtWorldLocationByGuid围绕世界位置设置目标缩放，并输出限制后的实际缩放值。
GetDefaultMap3DScaleGetMap3DScaleByGuid查询当前地图缩放。
ResolveDefaultMap3DZoomPivotWorldLocationResolveMap3DZoomPivotWorldLocationByGuid将期望的缩放中心解析到地图可用平面。
BeginDefaultMap3DDragAtWorldLocationBeginMap3DDragAtWorldLocationByGuid以指定世界位置开始拖拽。
DragDefaultMap3DToWorldLocationDragMap3DToWorldLocationByGuid更新世界位置拖拽，并输出地图内容中心。
PanDefaultMap3DByWorldDeltaPanMap3DByWorldDeltaByGuid按世界偏移直接平移地图。
BeginDefaultMap3DDragWithMouseBeginMap3DDragWithMouseByGuid使用玩家控制器的鼠标射线开始拖拽。
DragDefaultMap3DToMousePositionDragMap3DToMousePositionByGuid在按住拖拽输入时持续更新鼠标拖拽。
GetMouseLocationOnDefaultMap3DDragPlaneGetMouseLocationOnMap3DDragPlaneByGuid纯函数，获取鼠标射线与地图拖拽平面的交点。
EndDefaultMap3DDrag / GetDefaultMap3DDragStateEndMap3DDragByGuid / GetMap3DDragStateByGuid结束拖拽或查询当前拖拽状态。

棋子操作

推荐从 UGSMMapData 调用。添加棋子会返回最终 GUID 和完整数据对象；移动只需要目标瓦片与新的 FGSMPiecePlacement。

  • AddPieceToTileById / AddPieceToTile
  • UpdatePiece
  • MovePieceByGuidToTileId / MovePieceByGuidToTile
  • MovePieceDataToTileId / MovePieceDataToTile
  • RemovePieceByGuid / ClearAllPieceData

这些函数都会触发瓦片的棋子添加、更新或移除事件，从而同步已存在的 3D/2D 表现。

数据层导航

  • UGSMMapData::FindPathByTileIds
  • UGSMMapData::FindPathByTiles
  • UGSMMapSubsystem::FindPathByMapGuid
  • UGSMMapSubsystem::FindPathOnDefaultMap

返回 FGSMPathResult，其中 PathTiles 是瓦片数据对象。寻路不要求地图已经创建 3D 展示。
