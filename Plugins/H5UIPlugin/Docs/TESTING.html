最快验证路径

创建一个 Widget Blueprint，拖入 H5 UI View，将 URL 设置为 h5ui://plugin/showcase.html，再从关卡蓝图创建并添加到 Viewport。

Showcase 和 Vue 3 示例都已随插件提供，不需要复制页面、样式、图片、脚本或视频文件。

1创建空关卡

  1. 在 Unreal Editor 中选择 File > New Level > Empty Level。
  2. 保存为 L_H5UIPluginTest。
  3. 确认 Edit > Plugins > H5 UI Plugin 已启用。当前 SilverChoir 工程已经启用。

2创建全屏 Widget

  1. 在内容浏览器中选择 Add > User Interface > Widget Blueprint。
  2. 命名为 WBP_H5UIPluginTest。
  3. 打开 Designer，从 Palette 的 H5 UI Plugin 分类拖入 H5 UI View。
  4. 控件命名为 HtmlView，勾选 Is Variable。
  5. Anchors 设置为全屏拉伸，Left、Top、Right、Bottom 全部设为 0。

5验证 JavaScript

Showcase 底部的 JavaScript 面板由外部 showcase.js 驱动，页面内部状态变化不需要经过 Blueprint。

在 Blueprint 中也可以调用 Execute JavaScript，读取 Success、Result 和 Error 输出：

document.getElementById('js-status').textContent = 'Called from Blueprint';
ue.setData('last.event', 'JavaScript wrote UE data');
ue.getData('last.event');
为 HtmlView 绑定 On JavaScript Error 并连接 Print String，可直接看到页面脚本或 Execute JavaScript 的语法与运行错误。

6验证 Vue 3

插件现已内置 Vue 3 自定义渲染器。Vue 的组件树和响应式系统运行在 QuickJS 中，节点创建、属性更新和事件绑定通过 H5UI DOM 写入 RmlUi，并继续由 Slate 原生提交几何，不会切换到 CEF 页面纹理。

直接加载内置示例

  1. 选中 WBP_H5UIPluginTest 中的 HtmlView。
  2. 将 URL 改为 h5ui://plugin/vue-basic/vue-basic.html。
  3. 保持 Auto Load、Receive Input 和 Enable JavaScript 开启。
  4. 编译 Widget 并进入 PIE。这个页面不依赖 Blueprint 初始化数据。
操作验证的 Vue 能力预期结果
打开页面SFC 挂载、子组件、v-for显示三个状态组件，右上角为 Ready
修改 Pilot name事件绑定、ref、computed标题中的 Welcome 文本随输入更新
点击 Increment响应式状态与异步更新队列按钮中的计数从 0 依次增加
点击 Toggle detailsv-if 条件渲染说明文字在两种状态之间切换

Vue SFC 工程与构建

Vue 开发工作区位于 Plugins/H5UIPlugin/WebSDK。示例使用标准 .vue 单文件组件，但入口需要调用 Silver 提供的 createH5UIApp：

import { createH5UIApp } from '@h5ui-plugin/vue';
import App from './App.vue';

createH5UIApp(App).mount('#app');

安装依赖并生成 UE 可加载资源：

cd Plugins/H5UIPlugin/WebSDK
pnpm install
pnpm build

构建结果会写入 Resources/UI/sdk/h5ui-vue.global.js 和 Resources/UI/vue-basic/。页面脚本输出为经典 IIFE，因此当前不依赖尚未实现的 ES Modules。

已验证：UE 5.8 自动化测试会真实加载 Vue 产物、确认应用挂载，并点击 Increment 验证计数从 0 更新到 1。
本阶段边界：当前只完成 Vue 3 自定义渲染器和常用组件化能力；尚未实现 ECharts、Canvas、WebGL，也不保证依赖完整浏览器 DOM 或 runtime-dom 特性的第三方 Vue 组件可以直接运行。

7添加到屏幕并启用输入

打开 L_H5UIPluginTest 的 Level Blueprint，在 Event BeginPlay 后建立以下流程：

Event BeginPlay
→
Create Widget
WBP_H5UIPluginTest
→
Add to Viewport
→
Set Input Mode Game and UI
→
Show Mouse Cursor = true
Create Widget (Class=WBP_H5UIPluginTest, Owning Player=Get Player Controller)
-> Promote to variable TestWidget
-> Add to Viewport

Get Player Controller
-> Set Input Mode Game and UI (Widget to Focus 留空，Hide Cursor During Capture=false)
-> Set Show Mouse Cursor=true
不要使用 Set Input Mode UI Only：该模式会从 UE 层阻止输入进入游戏，插件无法让事件继续穿透。
进入 PIE 后，透明页面区域的鼠标和非编辑状态的键盘会传给游戏。点击输入框后键盘交给 HTML；点击透明区域或非编辑控件后，键盘重新交给游戏。点击页面中的 Edit pilot，还可以验证 UE 回调后主动聚焦输入框。

9验证视频播放

Showcase 使用以下原生节点。视频帧由 UE Media Framework 解码并保留在 Media Texture 中：

<video
  src="h5ui://plugin/media/showcase.mp4"
  autoplay
  loop
  muted>
</video>
UE 中应当自动播放、循环且静音。视频黑屏时先检查 Output Log 中的 Media Framework 信息，并确认 Win64 的 WmfMedia 可用。

11补充测试生命周期 API

Load HTML String 和 Close 不适合由页面内部触发，可在 Level Blueprint 绑定测试按键：

API测试方式预期结果
Load URL加载 h5ui://plugin/showcase.html显示完整 Showcase
Load HTML String传入严格闭合的简单 HTML 与 Base URL当前文档被内存页面替换
Reload点击 Reload view 并在 UE 分支调用 Reload重新加载并触发 Ready
Close绑定一个测试按键调用 Close页面卸载，状态变为 Unloaded
On Load Failed临时加载不存在的 URL输出明确错误文本
Execute JavaScript读取或修改带 ID 的页面节点返回结果，页面立即更新

调用 Close 后，执行 Load URL(h5ui://plugin/showcase.html) 即可恢复。

故障排查

现象检查项
页面空白URL 必须完整写为 h5ui://plugin/showcase.html；绑定 On Load Failed 输出错误。
无法键盘输入确认 Receive Input 已开启，使用 Set Input Mode Game and UI，并点击输入框取得焦点。
游戏收不到鼠标或键盘不要使用 Set Input Mode UI Only；确认两个 Pass Through 属性已开启，并为透明 HTML 根层设置 pointer-events: none。
视频黑屏确认 WmfMedia 可用，检查 Output Log 中的 Media Framework 错误。
中文输入法没有候选窗当前仅接收 Slate 已提交字符，完整 IME Composition Adapter 尚未实现。
性能数据一直是 0处理 RefreshStats 事件，将 Get Performance Stats 结果写入 perf.* 并同步。
JavaScript 面板停在 Starting确认 Enable JavaScript 已开启，并绑定 On JavaScript Error 查看具体错误。
Vue 页面空白确认 URL 为 h5ui://plugin/vue-basic/vue-basic.html，Enable JavaScript 已开启，并查看 On JavaScript Error。
Vue 构建后仍显示旧内容在 WebSDK 目录重新执行 pnpm build，然后对 HtmlView 调用 Reload。
按钮有事件但 Last event 不变化On UI Event 中设置 last.event 后必须调用 Synchronize Models。
