Map Transition System 插件使用手册

这份文档面向蓝图使用者和玩法程序。插件负责统一地图切换、加载 UI、资源预处理、主地图加载后的完成通知，以及地图处理类回调。

插件定位

`MapTransitionSystem` 是一个运行时地图切换插件。它把“打开地图前准备资源”“显示加载界面”“打开目标地图”“等待目标地图准备完成”“通知处理类并关闭 UI”收拢成一条统一流程。

适合处理

主菜单进入游戏、关卡间传送、带加载 UI 的地图切换、需要等待子关卡或异步初始化完成的地图。

不直接处理

具体存档逻辑、地图内 Gameplay 初始化细节、加载 UI 的视觉表现。这些由处理类、目标地图或 Widget 自己实现。

核心概念

概念 类型 用途
地图切换子系统 UMTS_MapTransitionSubsystem 真实持有切图状态、加载 UI、处理类实例和完成流程。
蓝图函数库 UMTS_MapTransitionBlueprintLibrary 提供可在任意蓝图中直接调用的入口，会自动从当前世界寻找子系统。
切换请求 FMTS_MapTransitionRequest 描述目标地图、处理类、加载 UI、完成延迟、是否需要手动通知等参数。
地图资源处理类 UMTS_MapTransitionHandler 承载预加载资源、地图加载完成、切图失败等事件。
加载界面 UMTS_MapLoadingWidget 显示当前切图阶段、进度、标题、提示文本等状态。

普通切图流程

当目标地图没有额外子关卡、异步初始化或 BeginPlay 后置流程时，使用默认模式即可。

  1. 调用 按地图对象切换地图 或 按切换请求切换地图。
  2. 保持 需要主动通知加载完成 为 false。
  3. 插件调用处理类 PreloadMapResources，显示加载 UI。
  4. 插件执行 OpenLevel 打开目标主地图。
  5. 主地图完成加载后，插件自动进入 OnMapLoaded，然后关闭加载 UI。

手动通知完成流程

当目标地图加载完成后，还需要继续加载流式子关卡、等待 Actor 初始化、准备镜头或 UI 时，启用手动通知模式。

关键参数：在切换地图时将 需要主动通知加载完成 设置为 true。此时插件会在主地图加载后保留加载 UI，并等待你主动调用 通知地图加载完成。
  1. 从任意蓝图调用 按地图对象切换地图，勾选 需要主动通知加载完成。
  2. 插件打开目标主地图，并在主地图加载完成后进入等待状态。
  3. 在目标地图的 GameMode BeginPlay、关卡蓝图或任意初始化对象里加载子关卡和地图资源。
  4. 你的异步初始化完成后，调用 通知地图加载完成。
  5. 插件调用地图处理类 OnMapLoaded，执行完成延迟，并关闭加载 UI。

蓝图函数库总览

蓝图函数库类为 UMTS_MapTransitionBlueprintLibrary，蓝图分类为 地图切换。下面的接口文档按手风琴方式组织，点击接口标题即可展开入参、出参和说明。

获取地图切换子系统 GetMapTransitionSubsystem · BlueprintPure 工具接口

从当前世界上下文获取 UMTS_MapTransitionSubsystem。一般不需要手动调用，除非你要直接访问子系统上的事件或状态。

入参 类型 说明
世界上下文 const UObject* 通常由蓝图节点自动从调用对象填入。
出参 类型 说明
返回值 UMTS_MapTransitionSubsystem* 当前 GameInstance 下的地图切换子系统；无有效世界时返回空。
按切换请求切换地图 SwitchMap · BlueprintCallable 完整入口

使用完整 FMTS_MapTransitionRequest 发起地图切换。适合需要配置目标地图名、目标地图对象、加载标题、提示、进度平滑速度、是否绝对切图等完整参数的情况。

入参 类型 说明
世界上下文 const UObject* 当前蓝图对象或可获取 World 的对象。
切换请求 FMTS_MapTransitionRequest 完整切图配置。至少需要设置 TargetMap 或 TargetMapName。
出参 类型 说明
返回值 bool 是否成功发起切换。返回 false 通常表示目标地图无效、GameInstance 不可用或已有切换正在进行。
如果请求中的 需要主动通知加载完成 为 true，主地图加载后不会自动关闭 UI，必须由目标地图调用 通知地图加载完成。
按地图对象切换地图 SwitchMapByObject · BlueprintCallable 常用入口

用软引用地图对象发起切换。这个节点是日常蓝图最推荐的入口：参数直观，能够直接指定处理类、加载界面和是否等待手动通知。

入参 类型 说明
世界上下文 const UObject* 当前蓝图对象或可获取 World 的对象。
目标地图 TSoftObjectPtr<UWorld> 要打开的目标主地图。
地图资源处理类 TSubclassOf<UMTS_MapTransitionHandler> 用于预加载资源、接收地图加载完成事件和失败事件。为空时使用默认处理类。
加载界面类 TSubclassOf<UMTS_MapLoadingWidget> 切图过程中显示的加载 UI。为空则不创建加载界面。
加载完成后延迟关闭秒数 float 处理类 OnMapLoaded 执行后，等待多少秒再关闭加载 UI。
需要主动通知加载完成 bool false 表示主地图加载完成后自动完成；true 表示等待目标地图调用 通知地图加载完成。
出参 类型 说明
返回值 bool 是否成功发起切换。 
推荐蓝图流程：
按地图对象切换地图
  目标地图 = Haven 主地图
  地图资源处理类 = BP_MTSHandler_NewGame
  加载界面类 = 你的 Loading Widget
  需要主动通知加载完成 = true
通知地图已准备好 MarkMapReady · BlueprintCallable 完成通知

通知插件目标地图已经准备好，可以继续执行地图处理类的 OnMapLoaded 和后续关闭 UI 流程。它是底层语义更通用的完成通知接口。

入参 类型 说明
世界上下文 const UObject* 当前蓝图对象或可获取 World 的对象。
就绪来源 FName 用于记录是谁发出的完成通知，例如 HavenGameMode、HavenSubsystem。
出参 类型 说明
无 void 重复调用会被忽略，只有第一次有效。
通知地图加载完成 NotifyMapLoadCompleted · BlueprintCallable 推荐完成通知

面向蓝图流程的完成通知接口。语义上更适合在目标地图完成流式子关卡、UI、镜头、Actor 初始化后调用。当前内部等价于调用 MarkMapReady。

入参 类型 说明
世界上下文 const UObject* 当前蓝图对象或可获取 World 的对象。
完成来源 FName 建议填写调用者名称，便于调试和加载 UI 状态展示。
出参 类型 说明
无 void 通知后插件进入 OnMapLoaded 和完成流程。
设置切换进度 SetTransitionProgress · BlueprintCallable UI 状态

手动更新加载 UI 显示的进度和加载内容。适合处理类或目标地图在异步初始化过程中给玩家反馈。

入参 类型 说明
世界上下文 const UObject* 当前蓝图对象或可获取 World 的对象。
进度 float 目标进度，建议使用 0.0 到 1.0。插件会按当前阶段限制可显示上限。
加载内容 FText 显示在加载 UI 上的当前步骤文案。
出参 类型 说明
无 void 更新会广播给当前加载 Widget 和监听者。

切换请求结构体

FMTS_MapTransitionRequest 是完整切图配置。使用 按切换请求切换地图 时会直接传入它。

字段 类型 说明
目标地图 TSoftObjectPtr<UWorld> 推荐设置。插件会从软引用解析出地图包路径并打开。
目标地图名 FName 当不使用地图对象时可直接填写地图名或包路径。
地图资源处理类 TSubclassOf<UMTS_MapTransitionHandler> 处理预加载、加载完成、失败回调。
加载界面类 TSubclassOf<UMTS_MapLoadingWidget> 加载过程中创建并添加到视口的 Widget。
加载标题 / 副标题 / 提示 FText 传给加载 UI 的展示文本。
加载完成后延迟关闭秒数 float 用于让完成动画或提示停留一段时间。
需要主动通知加载完成 bool 决定主地图加载完成后是自动进入 OnMapLoaded，还是等待目标地图主动通知。
进度平滑速度 float 加载 UI 进度追向目标进度的速度。设为 0 表示不平滑。
绝对切图 bool 传给 OpenLevel 的绝对 Travel 参数。

地图资源处理类

处理类基类为 UMTS_MapTransitionHandler。你可以创建蓝图子类，在里面实现地图切换前后的业务逻辑。

事件 / 函数 触发时机 建议用途
PreloadMapResources 发起切图后、打开地图前。 预读存档、准备临时数据、设置加载 UI 初始状态。
OnMapLoaded 地图被认定为完成加载后。 关闭前最后应用资源、派发玩法事件、同步 UI 状态。
OnMapTransitionFailed 切换请求无效、资源预加载失败等失败情况。 弹出错误提示、恢复菜单、记录日志。

加载界面

加载界面基类为 UMTS_MapLoadingWidget。插件会在切图开始时创建它，并在流程完成或失败后移除。

Widget 会接收 FMTS_MapTransitionPayload，其中包含阶段、进度、标题、副标题、提示、完成来源以及是否阻塞输入等信息。

建议加载 Widget 只关心展示，不要在 Widget 内部直接完成地图切换。完成通知应放在目标地图、GameMode、子系统或明确的初始化对象中。

Haven 地图示例

当前 Haven 的推荐蓝图逻辑如下：

  1. 主菜单或入口蓝图调用 按地图对象切换地图，目标地图选择 Haven 主地图。
  2. 勾选 需要主动通知加载完成。
  3. Haven 主地图加载完成后，在 GameMode BeginPlay 或其他初始化对象中调用 GFramework 的异步节点 根据配置文件加载所有子关卡。
  4. 根据配置文件加载所有子关卡 的 完成 引脚连接到 通知地图加载完成。
  5. 插件随后触发地图处理类 OnMapLoaded，加载 UI 关闭。
蓝图接线示意：
按地图对象切换地图(需要主动通知加载完成 = true)
    ↓ OpenLevel 到 Haven
Haven BeginPlay
    ↓
根据配置文件加载所有子关卡
    完成 → 通知地图加载完成
    失败 → 可显示错误或返回主菜单

常见问题

加载 UI 一直不关闭

检查当前切图请求是否勾选了 需要主动通知加载完成。如果勾选了，必须在目标地图初始化结束后调用 通知地图加载完成。

切图节点返回 false

通常是目标地图为空、目标地图名为空、GameInstance 不可用，或已有地图切换正在进行。先确认请求参数完整，再检查是否重复触发。

处理类 OnMapLoaded 没有触发

如果是普通流程，确认主地图确实完成 OpenLevel；如果是手动通知流程，确认 通知地图加载完成 被执行，且执行时仍处于地图切换状态。

进度条不到 100%

插件在部分阶段会限制进度上限，以避免 UI 在真实完成前显示满。完成流程执行后会进入 Completed 状态。
