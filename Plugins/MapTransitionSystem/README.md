# MapTransitionSystem 1.2

- 整张地图切换：沿用现有预加载处理器、加载界面和就绪通知接口。
- 动态子地图：数据资产指定地图、ID、名称和 Gameplay Tags；可设置位置/旋转，查询及批量卸载。
- 自动进度上限：为自定义初始化保留进度；整图加载界面按就绪通知和关闭延迟结束，与进度数值独立。
- 子地图处理类与按 ID 独立的加载进度事件。
- 运行时按处理对象加载子地图：独立读条、等待指定旧区域卸载、手动初始化完成通知；Handler 持续保留到卸载结束，可按 ID 查询。
