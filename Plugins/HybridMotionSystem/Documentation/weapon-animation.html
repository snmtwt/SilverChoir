武器准备与独立瞄准配置

准备姿态来自行为／装备 Chooser；普通瞄准使用新的“步枪_瞄准”姿势；掩体探出继续使用专用转身、待机和 AimOffset。三者各有清晰的入口。

01 / TRY IT

在测试场景中使用

  1. 打开 /Game/MVTest/Maps/L_MVThirdPersonTest 并运行。
  2. 装备选择“步枪”，行为选择“战斗”。按 B 或左侧按钮切换准备／瞄准。
  3. 按住鼠标左键调整方向，使用“瞄准俯仰”滑条测试抬枪和压枪。WASD 可测试站立和蹲伏移动。
  4. 点击“进入掩体测试”。掩体内按 B 转身探出，再按 B 收回。探出时调整瞄准只改变上半身，身体方向保持锁定；移动离开掩体后恢复普通运动和瞄准规则。

测试角色现已挂接 AR15 模型。双侧掩体的新瞄准零点按当前挂接校准；普通瞄准与武器更换后的枪口／握把仍需各自核对。

02 / ASSETS

资源在哪里

普通瞄准资源位于 /Game/HMS_Character/成年女性/动画/行为状态/战斗/步枪/瞄准。用户原始 步枪_瞄准 保持原样。

资源作用
AS_Rifle_FreeAim_Idle / Move保持参考手指和握持关系，加入小幅呼吸、移动起伏。
BS_Rifle_FreeAim_Hold按速度 0～300 混合瞄准待机与移动起伏；超出速度范围夹到边界。
AimOffset/AO_Rifle_FreeAim15 个采样：Yaw 为 −75、−37.5、0、37.5、75；Pitch 为 −60、0、60。
配置/DA_Rifle_FreeAim普通步枪瞄准：基础持枪、AimOffset、角度限制、进入／退出混合时间与左手稳定参数。
配置/DA_Rifle_Cover_RightStanding旧右侧配置保留。当前双侧掩体从 Cover Profiles 动态缓存各侧 DA_*_Aim，详见第 12 章。
03 / BLUEPRINT

动画蓝图中的连接

ABP_Famale 的 HMS | Aim Profiles 分类中增加了 FreeAimProfile 和 CoverAimProfile 两个蓝图变量。它们是可替换的数据资产配置；装备、行为、身体姿态和掩体状态仍保留原有蓝图所有权。

  1. CT_Famale 按“行为状态 → 装备类型 → 动作表”查询全身准备和运动姿势，身体姿态在动作表中筛选。
  2. 装备匹配且 RotationMode 为 Aim、角色不在 SM.State.Cover 时，启用 FreeAimProfile。
  3. 瞄准持枪混合空间叠加普通 AimOffset，再做参考握持稳定。从 spine_03 开始覆盖上半身，保留下半身、运动曲线和根运动。
  4. 进入掩体后普通瞄准关闭。Cover Chooser 和专用蒙太奇控制掩体姿势；只有探出完成且 AimReady 为真时，才叠加 CoverAimProfile 的偏移。
  5. 结果仍在原有全身 Slot、布娃娃／起身路径之前，专用动作保持原来的优先级。

更换步枪或行为风格时，可在蓝图中选择另一份 Profile，也可以另外使用 Chooser 查询 Profile。不要把不同基准的普通／掩体 AimOffset 混用。

04 / TUNING

调节手感与姿态

参数当前普通瞄准右侧站立探出
MaxYaw / MaxPitch75° / 60°65° / 45°
BlendInTime / BlendOutTime0.28 / 0.22 秒0.25 / 0.25 秒
HoldingPoseBS_Rifle_FreeAim_Hold不用；由 Cover Chooser 提供

混合时间控制进入／离开姿态的过渡。瞄准角度已使用现有 HMS 的平滑输入；超出范围会夹到边界，不会突然关闭姿势。普通模式身体转向由原有 Mover 与转身系统负责。掩体组件另有输入范围和 0.12 秒平滑：如果扩大掩体角度，要同时核对组件的 MaximumAimYaw / MaximumAimPitch 和动画实际采样范围。

StabilizeLeftHand 修正 AimOffset 采样之间混合产生的左手位置漂移。LeftHandGripOffset 是参考姿势中左手腕相对右手骨骼的坐标。当前值已按“步枪_瞄准”校准；保持原始手腕朝向和全部手指姿势，肘部沿当前动画方向调整，不拉长手臂。换成不同握法时需要重新校准这个值；也可以关闭稳定选项。它目前只作用于普通瞄准。

05 / AUTHORING

修改或扩展 AimOffset

普通采样使用 Mesh Space Additive，参考为 AS_Rifle_FreeAim_Idle 第 0 帧。中心采样应相对参考为零增量；采样只改变瞄准上半身，不加入根位移。重新制作握枪基准后，基础持枪、全部 AO 采样及左手相对位置必须一起更新。

掩体探出应按方向与姿态分别制作：右站、左站、右蹲、左蹲各自拥有进入／退出、探出待机和以该待机为参考的 AO。当前接通的是已有的右侧站立分支。扩展其他分支还需配置对应的 Cover Chooser、探出蒙太奇和 SupportedSlotTags，再按蓝图掩体枚举选择匹配 Profile。

编辑器蓝图可调用 Install Aim Profiles 接入两份配置，以及 Install Free Aim Grip 添加可编辑的 Two Bone IK 稳定节点。重复调用不会堆叠节点；工具不自动保存。资产构造可使用 Create Weapon Blend Space 和 Refresh Weapon Blend Space。新角色须先重定向到目标骨架，并指定正确的上身分支和左右手骨骼。

06 / PRODUCTION

后续接入枪械模型

先把枪挂到右手插槽，校准参考姿势中枪口／瞄具方向与左手握把。再根据实际枪械长度，将左手目标改为武器握把在右手骨骼空间中的位置。后续射击、换弹、后坐力、遮挡压枪、联网装备状态和 LOD 策略需要独立验收；本次完成的是可配置的动画瞄准层，不等同于这些玩法已经完成。
