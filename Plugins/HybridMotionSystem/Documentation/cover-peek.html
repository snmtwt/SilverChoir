进入掩体、转身探出与目标瞄准

进入由智能对象状态树和 Pose Search 选动画与起播时刻；贴靠和探出待机由动画蓝图 InCover 状态查询；转身阶段由 Mover 根运动驱动真实位置和朝向。

场景操作蹲伏进入资源位置状态流程目标瞄准更换动画
01 / TRY IT

在测试场景中使用

  1. 打开 /Game/MVTest/Maps/L_MVThirdPersonTest 并运行，选择“步枪”和“战斗”。
  2. 走到椅子前方靠近某一侧，点击“进入掩体测试”。系统选择最近的可用插槽；近处可从动画末段接入，远处先导航接近。
  3. 贴靠完成后按 B 或点击探出按钮，播放该侧探出动画并进入探出待机。
  4. 按住鼠标左键，瞄准鼠标射线命中的三维位置。人物身体锁定，只有专用 AimOffset 改变。俯仰滑条可清除目标并手动测试角度。
  5. 再次按 B 收回；转身途中也可反向。按 WASD 或右键导航离开，从当前姿势衔接运动。

方向约定：左／右均指“面对掩体时”的方向。人物背靠后，其解剖学左右可能相反。当前测试椅子 BenchSlot1 为左侧站立，BenchSlot2 为右侧站立；两个插槽的位置和 ID 保留。

当前左侧只配置了步枪动作，因此 BenchSlot1 的 User Tag Filter 要求 HMS.Weapon.Rifle。交互组件会将动画蓝图的武器类型与行为标签加入查询用户标签；空手角色仍使用右侧。左侧 Cover 配置开启 Leave Cover When Profile Unavailable：在左侧收起步枪时，探出中先收回，再退出掩体。右侧已有空手待机，可收回后留在掩体内。

01B / CROUCH ENTRY

站立接近，进入时下蹲

这套动作以现有左右站立进入的根轨迹和步伐为基础，接近末段逐渐下蹲；持枪上半身与手指使用当前“步枪_瞄准”姿势。腿部重新求解，保留原来的脚部接触轨迹，让膝盖朝鞋尖方向弯曲。

  1. 在测试场景选择“步枪”。点击新增的进入蹲伏掩体按钮，会寻找 HMS_CrouchCoverTest_Bench。它位于原测试椅子旁，沿世界 Y 方向相隔 350 厘米。
  2. 角色先站立接近，Pose Search 选择本侧 EntryFront、EntryLeft 或 EntryRight，以及合适的起播时间。下蹲段约为 2.53～3.60 秒；近距离仍可从中后段接入。
  3. 贴靠完成后，蓝图 CoverState 分别为 RightCrouched 或 LeftCrouched，进入 InCover 并从 SM.State.Cover 查询蹲伏待机。Mover 同时缩小碰撞胶囊，脚底世界高度保持不变。
  4. 按 WASD、右键导航或点击“离开掩体”退出，恢复进入前的站立意图。若椅面或其他障碍挡住起身，Mover 会在离开阻挡范围后再恢复站立高度。
位置 / 配置用途
掩体/运行时/RightCrouched、LeftCrouched每侧三条 AS_*_Entry 动画、三个 AM_*_Entry 蒙太奇、一个 AS_*_Idle 和 DA_*_Cover 配置。
/Game/MVTest/SmartObject/CrouchCoverSO_CrouchCover、ST_CrouchCover、DA_CrouchCoverQuery。交互配置启用“贴靠后保持蹲伏”，默认关闭，原站立配置不受影响。
插槽 Runtime TagsBenchSlot1 使用 HMS.Cover.LeftCrouched；BenchSlot2 使用 HMS.Cover.RightCrouched。两个插槽都要求 HMS.Weapon.Rifle。
进入查询与待机查询行为 → 步枪 → 插槽方向；进入时身体姿态仍是 SM.Stance.Stand，目标蹲姿由已占用插槽区分。贴靠后由 CoverState 枚举选待机。

当前范围：左右侧蹲伏进入与贴靠待机。尚未配置蹲伏专用探出、收回和 AimOffset，因此蹲伏时不开放 B 探出；站立探出仍使用原来的独立姿势与 AO。不要把普通瞄准 AO 直接套到蹲伏掩体上。

02 / ASSETS

资源与配置在哪里

用户导入原动画保留在 /Game/HMS_Character/成年女性/动画/行为状态/战斗/步枪/掩体/右侧。生成副本位于同级 运行时/RightStanding 与 运行时/LeftStanding；不要把副本重新导入覆盖原始源动画。

资产后缀作用
EntryFront / EntryLeft / EntryRight每侧三条进入动画及蒙太奇。查询窗口约从 1.93～2.00 秒开始，到 3.27 秒结束；接触时刻为 3.60 秒。近距离兜底还可选择后续有效的短尾段。
Idle背靠掩体的循环待机。
Peek / Retract探出与对应反向收回蒙太奇，时长各 1 秒。根轨迹包含侧移和约 87° 转身。
PeekIdle已扣除探出根位移／旋转的待机，避免胶囊体和网格体重复转身。
AimOffset/AO_*每侧独立 15 点 Mesh Space Additive，参考本侧 PeekIdle 的第 0 帧。
DA_*_Cover插槽、武器、可选行为标签，贴靠／探出姿势、蒙太奇对、瞄准配置和零点。
DA_*_Aim专用 AimOffset、角度范围和混合时间。

BP_MVThirdPersonTestPawn → CoverPeek → Cover Profiles 设置左右配置，按列表顺序选择首个匹配项。Required Behavior State 留空代表通用行为；如增加行为专用配置，应放在通用配置前。Cover Profiles 非空时使用配置资产，旧版组件的 Enter/Exit 字段仅用于兼容空配置列表。

03 / FLOW

查询、根运动和待机的分工

  1. 智能对象选定并占用插槽，状态树开始查询。一级仍是 BehaviorState，二级是 EquippedWeaponType；步枪进入叶表再按 Stance 与已占用插槽标签选择左右数据库。
  2. 原始动画约有十多米接近运动。只把末段加入搜索，运行时比较角色姿态、剩余根轨迹和插槽位置，并从查询结果的时间继续播放。导航目的地始终是交互目标，不是完整动画第一帧的位置。
  3. Motion Warping 对齐所选进入动画至插槽。DA_CoverQuery 的“按所选动画接触时刻进入待机”避免共用固定的绝对时刻。
  4. CoverState 仍保存在 ABP_Famale 的蓝图枚举里。进入 InCover 后使用 SM.State.Cover，从 Queries/行为/CT_行为_Rifle_Cover 中按站立／蹲伏、左右侧及探出状态选择待机；蹲伏目前仅开放贴靠。
  5. 按 B 时 DefaultSlot 播放根运动探出蒙太奇，Mover 移动胶囊体；结束后混出至本侧 PeekIdle。收回反向播放对应轨迹。智能对象占用在整个过程中保留。

蓝图函数 RefreshCoverPeek 在游戏线程缓存 CoverPeekState、CoverPeekAimReady、CoverPeekAimOffset 和 CoverAimProfile；动画工作线程只读取缓存。普通 FreeAimProfile 与掩体配置分开，不能把普通瞄准待机作为掩体 AO 的参考。

04 / AIM TARGETS

根据目标位置或 Actor 瞄准

接口用途
Request Peek(true / false)发起探出或收回；返回请求是否接受。
Can Peek / Is Aim Ready分别表示配置与状态允许探出、探出已完成。开火逻辑应额外检查 Is Aim Ready；视觉瞄准可以更早开始。
Set Aim Target Location设置世界坐标目标，原点 (0,0,0) 也有效。
Set Aim Target Actor每帧跟踪 Actor；Local Offset 是目标 Actor 局部坐标，例如胸口／头部偏移。
Clear Aim Target恢复外部瞄准方向输入。目标 Actor 被销毁或交互结束时清理目标。
Get Aim Origin / Get Aim Offset读取瞄准起点和已平滑、限制的相对角度。

目标方向由“目标世界位置 − Aim Origin”求得。Aim Reference Rotation 表示零偏移姿势中的持枪方向，相对探出后胶囊体朝向；侧身持枪通常不等于胶囊体前方。当前按角色上 Weapon 插槽与 AR15_Mesh 的 −X 枪管轴校准，右侧 Yaw 约 −96.30°、Pitch 约 −1.94°；新版左侧 Yaw 约 +91.03°、Pitch 约 −2.22°。

当前范围为 Yaw ±65°、Pitch ±45°，输入平滑 0.12 秒，AO 混入 0.25 秒、混出 0.20 秒。超过范围夹到边界，身体不会为了追目标而自动旋转。探出动画进行到 20% 时，专用 AO 开始按配置的 0.25 秒混合时间淡入，在探出过程中逐渐对准目标。动画结束时保留已积累的瞄准状态，避免再次归零后重新转向。

探出与瞄准同时进行：Cover 配置中的 Aim During Peek 控制是否启用；Peek Aim Start Fraction 是开始混入的归一化时刻，0.2 表示动画长度的 20%。具体混合时长仍由本侧 Aim 配置的 Blend In Time 控制。

Peek Aim Reference Curve 记录探出过程中原动画枪口相对胶囊的基础朝向，X 为 Yaw、Y 为 Pitch，时间为 0～1。当前左右侧各采样 31 点；逆向收回动画反向读取同一曲线。更改探出动画、网格朝向或武器挂接后需要重新采样，可通过编辑器接口 Configure Peek Aim Reference 写入采样结果。它支持撤销，不会自动保存。

动画蓝图将 CoverAimEnabled 与 CoverPeekAimReady 分开保存：前者由 Read Cover Aim Enabled 缓存，驱动 Calculate Cover Aim Inputs 的视觉启用输入（现有引脚名 AimReady）；收回时 CoverPeekState 已切回贴靠，但不能据此立即关闭视觉瞄准。后者保留“探出完成”的含义。掩体 AimOffset 放在 DefaultSlot 之后，经过 HMS_PostCoverMontage 缓存，防止被全身蒙太奇覆盖。世界目标方向先平滑，再减去当前动画参考朝向，因此不会把动画自身转身再延迟一次。

收回开始时保留当前瞄准姿势，随收回动画一起转身，不先回到默认瞄准姿势。收回阶段不再持续追踪世界目标，避免转回掩体时上半身反向扭转；中途重新探出会从当前可见朝向平滑恢复目标跟踪。Cover 配置中的 Aim During Retract 默认开启；Retract Aim End Fraction 默认 0.65，表示收回动画播放到 65% 时开始按本侧 Aim 配置的 Blend Out Time 淡出。当前 Blend Out Time 为 0.2 秒。瞄准只修正姿势，胶囊仍由探出根运动控制，完成后保持身体朝向锁定。目标超出本侧可瞄准范围时依旧受角度限制。组件中的 Maximum Aim Offset Speed 默认 720 度/秒，用于限制大角度跨界或中途反向时的姿势修正速度，避免相邻帧从一个瞄准极限直接跳到另一个极限。

更换枪或调整挂接时，请重新校准 Aim Reference Rotation 和 Aim Origin Socket／Offset。当前 Origin 使用 Weapon 插槽；正式射击应使用经过校准的枪口位置，并另外进行射线遮挡、命中与枪械后坐力处理。

05 / AUTHORING

接入后续动画

新版左侧的编辑基准：AS_LeftStanding_EntryFront、AS_LeftStanding_Idle、AS_LeftStanding_Peek 保留用户修订版本。对应的 _Runtime 副本用于实际播放：进入末尾对齐待机，探出起点对齐待机，并同步 IK 辅助骨骼。

EntryLeft / EntryRight 保留各自的根轨迹与接近步伐，采用新版正面进入的上半身姿势；PeekIdle 来自新版探出末帧，Retract 是播放副本的严格逆向；15 条 AO 样本以新 PeekIdle 为共同参考。再次修改基准动画后，需要重新生成这些衍生资源并刷新 Pose Search 与 AO；修改基准不会自动重烘焙所有副本。

  1. 准备同一侧的进入、贴靠、探出、探出待机、收回动画。探出和收回必须有根运动；待机应扣除已经交给胶囊体的根位移。
  2. 在 HMS 工具中为进入动画创建通知与轨迹，并确认允许接入窗口和接触时刻。原动画可以很长，只有末段进入数据库。
  3. 创建本侧 Cover 与 Aim 配置。为插槽设置对应 HMS.Cover 标签，在组件 Cover Profiles 添加配置。
  4. 使用 Configure Entry Side Chooser 配置进入叶表的方向／姿态筛选；使用 Configure Cover Idle Chooser 生成贴靠／探出配对行。工具支持撤销，不会自动保存。
  5. 如果收回是等长的严格逆向动画，启用 Exit Reverses Enter，可按互补时刻中途反向。不同的独立收回动画应关闭此项，反向输入会等待当前过渡完成。
  6. 校准实际墙边、碰撞胶囊、枪械长度和双手握持。当前侧移来自素材，不会自动测量任意墙宽；左侧生成素材可继续在动画工具中打磨。

当前完成站立步枪左右侧探出，以及左右蹲伏进入和贴靠。蹲伏探出、自动障碍检测、掩体内横移、联网同步和正式射击能力仍需继续实现。
