通知含义详解

逐个理解生成的通知：谁读取它、影响哪段时间、不会替你完成什么。

本页内容：这些通知分别代表什么
05 / NOTIFY REFERENCE

这些通知分别代表什么

工具将通知放在 HMS_Interaction 轨道中。这里的通知都是具有起止时间的 Notify State，并不是只触发一帧的事件。时间轴可能按原生通知类型显示名称；以下 HMS 名称是工具用于识别生成结果的事件名称。

S → C：接入开始到接触时刻

HMS.EntryWarp

原生类型：AnimNotifyState_MotionWarping / Skew Warp

作用：定义允许调整根运动的位置。运行时提供名为 SmartObject 的目标后，Motion Warping 在窗口内处理平移和旋转对齐。当前工具默认忽略 Z 轴对齐。

不负责：寻找智能对象、自动导航、挑选起播时间或检测身体已经碰到掩体。它也不会自动产生保持和退出动作。

怎么调：结束点应符合实际接触姿态。窗口太短而目标差异太大时，容易出现明显拉伸、急转或滑步，应同时检查目标偏移和候选动画。

0 → S：动画开头到接入开始

HMS.BlockBeforeEntry

原生类型：AnimNotifyState_PoseSearchBlockTransition

作用：禁止 Pose Search 把这段时间选为新的起播点。例如不希望角色重新播放动画前面很长的跑步段，就把它挡在查询范围外。

不负责：删除动画帧或缩短动画。手动播放 Montage 时，起播位置仍由播放调用指定。

特殊情况：接入开始为 0 时，前面没有要屏蔽的区间，因此不会生成这个通知。

E → 动画结束：接入末端之后

HMS.BlockAfterEntry

原生类型：AnimNotifyState_PoseSearchBlockTransition

作用：禁止直接跳到已经转入或贴靠的后半段，避免省略完整的进入过程。已经从前面进入的播放可以正常继续。

为什么从 E 开始，而不是 C：接触之前仍有一段必须完整播放的动作。它可以属于对齐窗口，但不应该再成为新的起播点。

不要把 Block Transition In 理解成 Exclude From Database。这里采用的是“禁止新接入”，目的是保留后续正常播放。它也不是 StateTree 的状态切换禁令。

在真实编辑器里识别它们

  1. 在下方找到“通知”，展开 HMS_Interaction 所在的轨道。
  2. 看窗口文字：MotionWarping 对应对齐窗口；两侧的 PoseSearchBlockTransition 对应接入限制。
  3. 点击窗口，在详情中检查类型与配置；MotionWarping 内的目标名称应与运行时一致。
