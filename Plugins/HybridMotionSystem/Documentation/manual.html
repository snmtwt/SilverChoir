01 — SMART OBJECT INTERACTION

智能对象交互动画

从一段进入动画开始，标出可以接入的时间、需要对齐的窗口，以及可供检查的根运动轨迹。

示例：M_Cover对象：测试椅子 / 掩体占位面向动画与关卡制作
当前可以使用

通知与轨迹生成、进入数据库范围更新，以及状态树驱动的移动中查询、连续进入及背对姿态保持测试。

仍待接入与验证

循环保持动画、掩体内移动和正式退出流程，以及多方向动作与联网。生成通知不会自动创建整套交互资产。

第一次使用 → 操作步骤找到菜单，填写参数，检查生成结果。想理解通知 → 含义详解结合时间轴与截图认识每个窗口。再次制作 → 覆盖规则修改参数后更新，理解失败提示。遇到问题 → 排查清单按症状检查动画与运行时接线。

01 / CONCEPTS

先区分：查询、对齐与轨迹

三种数据解决不同的问题。理解它们之后，就能知道该调时间、调目标，还是检查动画本身。

查询决定“从哪里播”

Pose Search 比较角色当前姿态与候选动画，返回一个适合的起播时间。接入限制通知决定哪些时间可以成为新的起点。

对齐决定“在哪里落下”

Motion Warping 在指定时间窗口内调整根运动，使角色尽量对齐运行时提供的目标位置和朝向。

轨迹说明“动画怎么移动”

参考曲线记录动画已有的根骨运动，帮助检查位移、旋转和剩余距离。它们不会自行驱动角色或自动配置查询数据库。

允许接入开始，是动画中的秒数。它不要求角色先移动到某个固定世界坐标并停住。连续接入的目标，是在移动中查询合适的帧，然后交给根运动。
