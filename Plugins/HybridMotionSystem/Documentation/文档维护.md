# 使用手册维护

入口为 `manual.html`。独立章节为 `interaction-*.html` 与 `character-testing.html`，共用 `assets/manual.css`；图片均为本地 PNG，页面不依赖网络或 JavaScript。

新增章节时：

1. 复制相近的章节页面，修改标题、简介、正文与本页目录。
2. 在所有章节的左侧导航加入新页面链接，并仅给当前页设置 `aria-current="page"`。
3. 更新上一章 / 下一章链接及页码。
4. 在 assets 中保存实际截图，提供描述性替代文本和图注。清楚区分实拍截图、示意图及建议参数。
5. 介绍功能时区分已实现行为与计划；修改运行时代码或生成规则后同步更新对应章节。
6. 检查页面间链接、锚点、图片加载，以及窄屏表格与时间轴的横向滚动。

旧版 `index.html` 保持原内容，仅增加新手册入口。已有 Markdown 技术说明继续作为补充资料。
