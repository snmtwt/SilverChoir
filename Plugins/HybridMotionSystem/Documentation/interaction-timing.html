时间参数与时间轴

理解三个时间点的区别，确定哪些帧可以接入、何时完成对齐。

版本说明：本页旧截图中的 M_Cover 时间参数仅为历史示例；当前三方向资产、通知同步与测试方式请见第 07 章。

本页内容：参数怎么填用一张时间轴读懂通知
03 / PARAMETERS

参数怎么填

界面参数含义设置方法
允许接入开始（秒）最早允许被查询选为新起播点的时刻，同时是对齐窗口的开始。放在转身动作之前，保留一点步态供姿态匹配。越靠后，可用候选越少。
允许接入结束（秒）可选择新起播点的末端；此后的动画仍可继续播放。放在明显贴靠姿态之前，并且必须早于接触时刻。不要把它设为 0 来表达“自动”。
对齐结束 / 接触时刻（秒）希望根运动对齐到目标的时刻，也是 Motion Warping 窗口终点。看身体与物体的实际接触姿态来确认；根骨停止移动只是参考。
对齐目标名称运行时用于查找目标变换的名字。现有状态树使用 SmartObject。动画窗口和运行时提交的名字必须一致。
开启根运动生成时启用动画根运动，并将根骨锁定方式设为动画首帧。用于已有根骨位移的进入动画。取消勾选表示不修改现有开关，不会主动关闭已经启用的根运动。
生成根轨迹参考曲线从根骨烘焙五条浮点曲线。需要检查轨迹或更新剩余距离时勾选。取消勾选会保留旧曲线，不会删除它们。
0 ≤ 接入开始 < 接入结束 < 接触时刻 ≤ 动画长度

时间单位为秒。如果你记录的是帧号，用“帧号 ÷ 对应采样帧率”换算，并核对时间轴使用的是从 0 开始的帧索引还是显示序号。

04 / TIMELINE

用一张时间轴读懂通知

M_Cover 长约 3.233 秒。下面采用工具建议值：接入开始约 1.567 秒，接入结束约 1.967 秒，接触时刻约 2.167 秒。

例如查询选中 1.80 秒：角色从 1.80 秒开始播放，继续经过接入结束点，再到达接触时刻。经过“禁止新接入”区域不会让正在播放的动画停止。
