创建通知与轨迹

从打开 M_Cover 到检查生成结果，按步骤完成第一次制作。

版本说明：本页旧截图中的 M_Cover 时间参数仅为历史示例；当前三方向资产、通知同步与测试方式请见第 07 章。

本页内容：跟着做：从 M_Cover 开始
02 / QUICK START

跟着做：从 M_Cover 开始

以当前项目中的掩体动画为例：

/Game/HMS_Character/成年女性/动画/行为状态/通用/空手/Cover/M_Cover

先找对编辑器

打开的是动画序列，顶部应出现 HMS工具。菜单里的“创建进入通知与轨迹…”位于“智能对象交互”分组。

第一次使用时，先阅读本章，再到下一章理解时间参数。不要把 0 当作自动填值。

  1. 打开源动画序列

    双击 M_Cover，在动画编辑器中预览。工具目前处理 AnimSequence；如果打开的是 Montage，请先进入它引用的源动画序列。

  2. 进入 HMS 工具

    点击顶部 HMS工具 → 创建进入通知与轨迹…。原有骨骼权重曲线、转身曲线功能也在这个菜单中。

  3. 确定三个时间

    拖动动画时间轴，找出转身前可匹配的步态片段，以及身体希望贴靠物体的时刻；填写接入开始、接入结束和接触时刻。

  4. 设置对齐目标与生成项

    本次 CoverQuery 测试使用 HMSInteraction；原坐椅任务使用 SmartObject。名称必须与交互配置对应。按需勾选开启根运动与生成根轨迹参考曲线。

  5. 生成、检查、保存

    点击 一键生成 / 更新通知与轨迹，确认下方显示成功。检查通知轨道和曲线，再保存动画。若需要撤回，使用 Ctrl + Z。

  6. 同步进入数据库

    使用 CoverQuery 测试时，选择“进入查询数据库”为 PSD_Entry，点击“更新进入查询范围与索引”，然后保存数据库。详见第 07 章。

生成后看哪里

第一处：动画编辑器下方“通知”里出现 HMS_Interaction。

第二处：“曲线”分组显示五条 HMS_Interaction_ 开头的曲线。

第三处：时间轴上可以看到 PoseSearchBlockTransition 与 MotionWarping 窗口。曲线列表只能证明数据存在，还要检查时间范围和曲线值。
