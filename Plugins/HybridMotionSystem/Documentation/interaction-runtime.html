智能对象交互动画 / 07

接入交互运行流程

制作好动画数据之后，还需要把查询、状态树与根运动播放连接起来。

本页内容：通知准备好之后，如何参与交互
07 / THREE-WAY COVER

三方向进入掩体 · 2026.09.08

在 L_MVThirdPersonTest 中点击“进入掩体测试”。角色使用椅子上的 SO_CoverQuery 与 ST_CoverQuery，配置 DA_CoverQuery 指向 CoverThreeWay/CHT_Entry。

先查询当前位置，再决定是否移动

Chooser 返回 CoverThreeWay/PSD_Entry。Pose Search 同时比较剩余根位移、剩余转向和脚步姿态，返回蒙太奇与起播时间。当前位置有合适结果时直接播放剩余动作。开启“允许近距离强制进入”后，250 cm 内即使姿态匹配失败，也会按当前位置到目标的剩余距离、方向选择有效动画与起播帧，并通过混合和根运动对齐完成进入。范围外向交互目标导航，持续查询；不再先去动画轨迹上的固定接近点。

支持正面、左侧、右侧三个动画。动画名称中的方向是制作时的方向，不是摄像机屏幕上的左右。旋转椅子时，目标和接近方向随智能对象旋转。

移动切入动画时的过渡

在 DA_CoverQuery → Entry Transition 中调整“移动进入混合时长”，默认 0.4 秒。角色仍在移动时，将进入蒙太奇的混入时间延长到这个值，让当前移动姿势逐渐过渡到进入掩体的姿势。它是姿势混合时间，不会延后导航交接，也不会让角色先停住等待。

设置为 0 使用蒙太奇原有混合设置；静止接入继续使用蒙太奇原设置，当前三个测试蒙太奇为 0.2 秒。若蒙太奇本身设置了更长的混入时间，会优先保留该时长。运行时还会按剩余对齐时间限制实际混合长度，确保接触目标前能完成混合。“最短贴靠时长”管理近距离动作的播放速度，与此参数分别调整。代码只修改这次播放实例，不修改共享动画资产。运行时 SelectedEntryBlendTime 可查看本次实际使用的混合时间。

近距离强制进入

打开 CoverQuery/DA_CoverQuery，在 Entry Fallback 下设置“允许近距离强制进入”和“强制进入距离”。本测试已开启，距离为 250 cm。普通距离优先使用 Pose Search；强制回退不使用姿态评分阈值，但继续检查骨架、根运动、对齐窗口、混合时长和保持时间。它不是瞬移，也不能保证任意方向都同样自然。较大角度或距离修正可能产生滑步，需要更合适的动画来改善。

诊断属性 UsedForcedEntry 表示本次是否使用强制回退；此时 SelectedEntryCost 为 -1，避免把几何回退评分误当作 Pose Search 代价。关闭选项后，未匹配且导航结束仍会报告失败。已移除未使用的 RouteDistance 参数，查询进入始终朝实际交互目标导航。

已经很近、背朝掩体时 · 2026.09.10

Entry Fallback 新增“近距离贴靠选段范围”，默认 80 cm，距离从角色脚底投影位置量到实际插槽目标。它需要同时开启“允许近距离强制进入”，且受“强制进入距离”限制。设置为 0 可关闭这项贴靠选段。“最短贴靠时长”默认 0.45 秒：剩余片段太短时只降低播放速度，给位置修正和姿势混合留下时间。普通距离的进入速度不受此参数影响。

在此范围内会重新比较三个动画，并允许在 Motion Warping 通知的后半段选择起播帧，包括普通数据库查询结束之后的收尾。已经接近最终朝向时，优先选择无需明显转身的片段；即使剩余根位移小于 5 cm，也可以混入。系统仍为蒙太奇混入预留时间，并在接触结束时校验位置和朝向。因此无需退回动画起点，也不会仅因角色静止、普通姿态查询失败而放弃可用的收尾片段。

本 ABP 的 Offset Root Bone → Reset Every Frame 已连接 ShouldResetOffsetRoot。DefaultSlot 交互播放期间，以及输出带 Interaction 标签的掩体待机期间，重置移动遗留的偏移，由 Mover 与交互根运动控制最终朝向。只把模式设为 Release 并不足够：开启旋转速度限制时，静止保持姿态的根运动为零，可能让之前的错误旋转一直保留。接入自己的动画蓝图时，请同时接好这个重置输入。

此功能使用已有动作做混合与位移修正，不会生成新的后退步伐。若希望背朝掩体时仍有真实的后退小步，可继续补充短距离后退贴靠动画；它们同样需要统一接触位置、最终朝向和对齐通知。增大贴靠范围会增加滑步的可能，建议先保留 80 cm。

插槽与最终站立位置

最终进入目标由智能对象插槽和 DA_CoverQuery 的 Target Offset 共同决定。当前配置的位置偏移已由 (80,0,0) 改为 (0,0,0)，角色地面根部直接对齐实际占用的插槽。检查误差时应比较根部与插槽，不要使用位于半身高度的胶囊中心。椅子插槽原本用于坐姿；用于站立掩体时，应将插槽放到角色最终站立的地面位置，否则即使对齐准确也可能与椅面重叠。

HMS.EntryContact 是什么

“更新进入查询范围与索引”现在会把源动画 HMS.EntryWarp 的结束时刻同步为蒙太奇上的 HMS.EntryContact 标记。它给查询索引提供每个动画各自的接触时刻，不负责触发播放或占用。不要手动移动它来替代修改源动画；修改源动画通知后再次更新数据库，并同时保存动画、蒙太奇和数据库。

添加或替换动画时

  1. 统一最终根位置、最终身体朝向和掩体参考位置，保留真实位移与转向。
  2. 在交互副本上使用 HMS工具生成通知与轨迹，设置可接入区间和接触时刻。终点归零且带非零起点的动画需检查根锁定，当前副本使用 Zero。
  3. 创建 DefaultSlot 蒙太奇。保持用蒙太奇关闭自动混出；配置中的保持时间必须晚于接触时刻、早于动画末尾。
  4. 将蒙太奇加入 CoverThreeWay/PSD_Entry，更新查询范围与索引，保存修改。
  5. 测试近距离静止起步、三个方向移动进入、取消与离开。不同动作长度时，保持时间仍由当前配置统一管理，需选一个所有动画都有效的时间，或分开配置。

关闭强制进入时，当前位置与动画中段相差过大仍可能无法匹配。开启后可以修正这类误差，但强制进入不会自动生成绕开掩体的动画路径；从掩体背后强制进入可能穿过对象，正式使用时仍应补充绕行动画或限制可交互侧。近距离静止接入的自然程度还取决于该帧是否适合从站立姿态混入。
